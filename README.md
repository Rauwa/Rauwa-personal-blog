# Personal Knowledge Hub (LinkedIn + Medium + edX)
Platform pribadi yang menggabungkan:
1. **Identitas & Kredibilitas Profesional** (Gaya LinkedIn)
2. **Karya Tulis & Opini Mendalam** (Gaya Tipografi Editorial Medium)
3. **Kelas Terbuka Gratis Bersesi** (Gaya Ruang Belajar edX dengan Video & Catatan)
4. **Ruang Pengelola / Admin Terlindungi** (Bisa edit isi langsung dari browser)

---

3. Website akan langsung terbuka seketika di Google Chrome atau Microsoft Edge Anda!

---

## 🔐 Cara Masuk ke Halaman Pengelola (Admin Dashboard)

Untuk mengganti nama, menulis artikel baru, atau menambah kelas video:
1. Di pojok kanan atas website, klik tombol hitam **[ 🛡️ Kelola / Admin ]**.
2. Masukkan data akses default:
   * **Username:** `admin`
   * **Password:** `admin123`
3. Klik **"Masuk ke Dashboard"**.

### Apa Saja yang Bisa Anda Lakukan di Admin?
* **Tab 1 (Profil):** Mengubah nama lengkap, gelar/headline, bio misi Anda, tautan LinkedIn, dan email kontak.
* **Tab 2 (Rekam Jejak & Keahlian):** Menambah, mengedit, atau menghapus riwayat pengalaman/karier/pengabdian (peran, institusi, periode, deskripsi kontribusi) serta daftar keahlian utama.
* **Tab 3 (Karya Tulis):** Menulis artikel esai baru, mengedit tulisan, atau menghapus artikel. Teks langsung terbit dengan gaya baca Medium (lengkap dengan estimasi waktu baca otomatis).
* **Tab 4 (Kelas Terbuka):** Membuat kursus baru, memasukkan link video YouTube (Sesi 1, Sesi 2, dst.), dan mengetik catatan pendukung materi.
* **Tab 5 (Cadangan & Akses):** 
  * Mengganti password admin Anda.
  * **Unduh File Cadangan (Export JSON):** Mengamankan seluruh isi tulisan, pengalaman, dan kelas Anda ke dalam 1 file kecil di komputer Anda.
  * **Pulihkan Data (Import JSON):** Mengembalikan isi data kapan pun Anda butuhkan.

## 🌐 Cara Mempublikasikan ke Internet Secara Rp 0 (Gratis Selamanya)

Ketika Anda sudah selesai mengisi data dan ingin agar website ini bisa diakses siapa saja di dunia:
1. Buat akun gratis di **[GitHub](https://github.com)**.
2. Buat repository baru (misal diberi nama `blog-pribadi`), lalu unggah file-file dari folder ini.
3. Buka **[Vercel](https://vercel.com)** (gratis selamanya), klik *"Import Project"*, dan pilih repository GitHub Anda.
4. Dalam 30 detik, website Anda langsung aktif dengan alamat resmi gratis seperti `namaanda.vercel.app` lengkap dengan keamanan SSL HTTPS (gembok hijau)!

## 🎨 Fitur Utama Tampilan
* **Tipografi Elegan Medium:** Menggunakan font editorial *Newsreader* dan *Plus Jakarta Sans*, spasi baris 1.8x, dan indikator progres membaca di bagian atas layar.
* **Ruang Belajar edX:** Pemutar video 16:9 yang responsif, daftar sesi modul di sidebar kiri yang bisa ditandai selesai (*checklist*), serta navigasi Sesi Sebelumnya / Sesi Selanjutnya.
* **Tema Gelap / Terang (Dark Mode):** Tombol bulan/matahari di navigasi atas untuk kenyamanan membaca di malam hari.
* **100% Responsif:** Tampil rapi dan proporsional baik di layar ponsel (HP), tablet, maupun monitor laptop.
